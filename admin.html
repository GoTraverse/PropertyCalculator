Stripe Integration

Store sensitive keys (sk_live_…, whsec_…) only in Netlify → Site Settings → Environment Variables — never in this form.
Setup: Add STRIPE_PUBLISHABLE_KEY, STRIPE_SECRET_KEY, STRIPE_WEBHOOK_SECRET to Netlify env vars. Webhook endpoint: /.netlify/functions/stripe — events: checkout.session.completed, customer.subscription.deleted

Google Sign-In

Setup: Go to Google Cloud Console → APIs & Services → Credentials → Create OAuth 2.0 Client ID (Web application). Add https://equitysight.app as an authorised JavaScript origin. Paste the Client ID above and save. Optionally set GOOGLE_CLIENT_ID in Netlify env vars for server-side verification.
Leave blank to hide the Google Sign-In button.
