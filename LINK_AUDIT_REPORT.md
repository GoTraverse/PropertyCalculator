## Appendix: HTTP Status Code Reference

| Code | Meaning | Action |
|------|---------|--------|
| 200 | OK - Page working | Keep |
| 301 | Moved Permanently | Update to new URL |
| 302 | Found/Temporary Redirect | Investigate & update |
| 404 | Not Found | Remove or update to working URL |
| 403 | Forbidden | Usually bot-blocking, likely OK in browser |
| 000 | Timeout/Connection Error | Retest or find alternative |
